유니패스 API 도우미 개인정보처리방침

시행일: 2026년 11월 9일

유니패스 API 도우미(이하 "확장 프로그램")는 관세청과 관계없는 개인이 만든 크롬 확장 프로그램입니다. 이 방침은 확장 프로그램이 어떤 정보를 다루는지 설명합니다.

1. 다루는 정보

  • API 인증키: 사용자가 키 테스트 화면에 입력한 유니패스 OpenAPI 인증키
  • 키 테스트 입력값: 개인통관고유부호, 이름, 휴대폰 번호
  • 안내 진행 상태: 도우미가 켜져 있는지와 현재 안내 단계

2. 저장 위치

API 인증키와 안내 진행 상태는 사용자 기기의 크롬 확장 저장소(chrome.storage.local)에만 저장됩니다. 개인통관고유부호, 이름, 휴대폰 번호는 저장하지 않습니다. 개발자는 이 정보를 받거나 볼 수 없습니다.

3. 외부 전송

  • 사용자가 [조회 테스트]를 누를 때에만 인증키, 개인통관고유부호, 이름, 휴대폰 번호가 관세청 유니패스 API(unipass.customs.go.kr)로 직접 전송됩니다.
  • 안내 단계 데이터(JSON)를 GitHub(api.github.com)에서 받아옵니다. 이때 사용자 정보는 보내지 않습니다.
  • 그 밖의 서버로는 어떤 정보도 보내지 않습니다.

4. 판매·공유

수집한 정보를 판매하거나 제3자와 공유하지 않으며, 확장 프로그램의 목적 외의 용도나 신용도 판단에 사용하지 않습니다.

5. 삭제

확장 프로그램을 삭제하면 기기에 저장된 모든 정보가 함께 삭제됩니다.
